# PlayerInv LightWeight
Provides players with unlimited storage vaults. Players can customize vault attributes and automatically pick up items into vaults.

## Introduction
* Players can open vaults from any location to store any mod or special Lore items
* OP administrators can query online/offline player vaults and view each vault's item contents
* Independent support for the LuckPerms plugin, enabling cross-server permission sync and timed permission grants
* Fully customizable vault menus and vault count

## Features
* Supports server versions `1.12.X - 26.X`
* Supports server cores `Folia` `Purpur` `PaperSpigot` `Spigot` `Arclight` `CatServer` `Mohist` and more
* High plugin performance — no item duplication bugs found
* Vault menu and query menu are fully customizable via config files (e.g., DeluxeMenu)
* Custom large / medium vault counts with no upper limit
* Vaults can be granted or appended via vouchers / commands
* Supports storage of mod items
* Customizable item blacklist to prevent certain items from being placed in vaults
* All prompt messages are customizable
* Vault titles and sound effects are customizable
* Admins can query all vault contents of any player, with full take-out and deposit access
* Supports `MySQL` storage; defaults to `SQLite` local database
